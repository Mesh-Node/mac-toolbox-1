# Mac toolbox

A starter Hermes toolbox for a Mac. The current scripts open a tab, print the new tty and the donor tty, and type a line into a named tty.

## Download

```
git clone https://github.com/Mesh-Node/mac-toolbox-1.git
```

Or use the Code button on this page and download the ZIP. Unzip it.

## Open in Obsidian

1. Open Obsidian.
2. Choose Open folder as vault.
3. Select the `vault` folder inside `mac-toolbox-1`.

## Then

Read `SETUP.txt` beside that vault. It sets Grok as the Hermes chat default and points at local Honcho. The current scripts are in `scripts/`.
