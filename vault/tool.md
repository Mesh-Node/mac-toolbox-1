# Tool

A **tool** is a note under `tools/`.

It is a description plus a command pointer. The executable lives in `scripts/`.

The note is the tool. The command is what the note points at.

Write the note when the command first exists. A command awaiting a run on the Mac keeps evidence `untested`.

The current tools are [[new-tab]] [[inject]] [[type-hermes]] [[hop]]. Pattern: [[inbox/admit]].

See [[toolchain]].
